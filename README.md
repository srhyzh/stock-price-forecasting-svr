# Stock Price Forecasting with Support Vector Regression

## Overview

This project explores the use of machine learning for stock price
forecasting. Support Vector Regression (SVR) is combined with
technical indicators derived from historical market data.

The project was developed as part of my work in quantitative
finance and data science.

## Objective

The objective is to investigate whether historical price information
and technical indicators can be used to forecast future stock prices
using Support Vector Regression.

## Methodology

The analysis includes:

- Data preparation and cleaning
- Technical indicator calculation
- Feature engineering
- Support Vector Regression
- Hyperparameter optimization using GridSearchCV
- Time-series cross-validation using TimeSeriesSplit
- Evaluation using regression performance metrics

## Technical Indicators

The model uses several technical indicators, including:

- Moving Average Convergence Divergence (MACD)
- Exponential Moving Averages (EMA)
- Bollinger Bands
- Relative Strength Index (RSI)
- Stochastic Oscillator

## Limitations

Financial markets are noisy and non-stationary. Historical predictive
performance should therefore not be interpreted as evidence of future
investment performance.

The project is intended as a data-science and research exercise and
not as investment advice.
